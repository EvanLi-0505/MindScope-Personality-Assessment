## 3. 本阶段发现并修复的问题

| 问题 | 怎么发现的 | 修复 |
|---|---|---|
| **之前所有便携版的 `LICENSE.txt` 开头的破折号是乱码**（"窶・"），网页版 `DEPLOY.txt` 也一样 | 写发布测试时发现 PowerShell 读中文出错，回头检查了旧包 | Windows PowerShell 5 把无 BOM 的脚本按系统代码页读取。打包脚本改为带 BOM 的 UTF-8，许可证文件按 UTF-8 读取；重新打包后核对无乱码 |
| 离线测试第一次报告了两条对外连接 | 发布测试 | 排查后确认是误报：Windows 会复用进程编号，一个无关的老进程被当成了 WebView2 的子进程。改为只统计在 MindScope 启动之后创建的子进程，并记录进程名；之后多次运行均无对外连接 |
| 网页恢复测试的预期写错了 | E2E | 无效文件在改动前就被拒绝，不需要先备份，这是正确行为；改了测试 |
