## D. 需要你人工确认的项目

1. 在你自己的电脑上解压 `MindScope-0.6.0-win-x64-portable.zip` 运行，做一次测评并导出 PDF。
2. 如果有条件，在一台 Windows 10 电脑上试运行（我的测试环境是 Windows 11）。
3. 网页版：把 `MindScope-0.6.0-web.zip` 部署到一个 HTTPS 地址（或本机 `npx serve`），在手机浏览器上打开试用。
4. AI：有可用的百炼 Key 时再验证（不影响其他功能）。
