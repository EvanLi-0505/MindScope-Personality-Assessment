## 1. 交付内容

| 功能 | 说明 | 关键文件 |
|---|---|---|
| 启动动画 | Logo 淡入 → 「让每一个人都能免费体验高质量的心理测评」→「愿每一个人都能拥抱健康的心灵」→ 淡出（约 3.5 秒）。与数据库启动同时进行；点击或按键可跳过；「设置 → 外观 → 启动动画」可关闭；系统开启"减少动画"时改为静态显示；每次启动只播放一次 | `SplashScreen.vue`、`splash.ts` |

## 3. 本阶段发现并修复的问题

| 问题 | 怎么发现的 | 修复 |
|---|---|---|
| 测评选择页加载完成时会把默认人物卡**覆盖掉用户已经点选的人**，导致测评记到错误的人名下 | 浏览器里用脚本快速操作时，小林的结果记到了"我自己"名下 | 只在用户还没选择时设置默认值；E2E"选乙必须选中乙"覆盖 |
| 答题页刚出现时按下的第一个键会丢失 | 同上 | 页面挂载后立即监听键盘 |
| 对比图正负方向与两侧字母相反（I 型的条画向 E 一侧） | 查看 E2E 截图 | 反转横轴，与结果页维度条方向一致；表格改为"I 67"这种写法 |
| 文案里的 `|` 被 vue-i18n 当成复数分隔符，说明文字只显示一个"S" | 查看 E2E 截图 | 改写文案，并新增自动检查防止再出现 |
| 两次结果都是快速测试时，不显示"可以直接比较" | E2E 失败 | "含快速测试"只作为提醒，不影响可比性判断 |
| 同一天多次测评，趋势图横轴标签完全相同 | 查看截图 | 同一天有多次时显示具体时间 |
| 打印时一张趋势图被拆在两页 | 查看冒烟测试 PDF | 图表打印时不跨页，标题跟随图表 |
| 页面跳转后残留确认对话框 | 浏览器测试 | 路由切换时自动关闭对话框 |

## 4. 已知限制

1. 同一分钟内的多次测评，趋势图标签时间仍然相同（实际使用中几乎不会出现）。
2. 八功能趋势图同时显示 8 条线时较拥挤，可点击图例隐藏部分功能。
3. 对比最多 5 次结果。
4. 题库尚未经过真人验证（同 Phase 2）；源码链接仍是占位符。

## 5. 你可以这样验收

1. 解压 `release/MindScope-0.3.0-win-x64-portable.zip` 并运行，观察启动动画（可点击跳过；「设置 → 外观」里可以关闭）。
2. 给同一张人物卡做两次测评，打开「人物」→ 点击人物卡，查看统计、相处方式和趋势图。
3. 在测评记录里勾选两次结果 →「对比所选」。
4. 再建一张人物卡做一次测评，到「历史与对比」里筛选，并勾选两个人的结果对比，看"相处参考"。
5. 编辑人物卡 →「上传图片」设置头像。
