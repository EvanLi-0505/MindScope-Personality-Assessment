# Phase 3 — 人物卡详情与历史记录：计划

> 日期：2026-10-23　状态：已完成，见 [PHASE3_报告.md](PHASE3_报告.md)

## 1. 目标

点开一张人物卡，就能看到这个人的完整画像：基本信息、最近一次结果、一共做了几次测评、最近测评时间、性格描述、最佳相处方式，以及多次测评的变化趋势；还能把任意几次结果（同一个人或不同的人）放在一起比较。

## 2. 范围

| 包含 | 说明 |
|---|---|
| 启动动画 | Logo + 两句标语淡入淡出，可跳过、可在设置中关闭、尊重"减少动画"系统设置 |
| 人物卡详情页 `/profiles/:id` | 基本信息与标签、统计（次数/最近时间/最近类型/未完成）、最近结果摘要（四维 + 八边形）、性格描述与**最佳相处方式**、四维趋势图、八功能趋势图、历史列表（按模式筛选、勾选对比、删除单次记录）、导出 PDF |
| 历史页 `/history` | 所有人物的全部结果，按人物 / 模式 / 时间筛选；类型分布图、每月测评次数图、每人测评次数图 |
| 对比页 `/compare?ids=…` | 2–5 次结果并排：类型、四维分组条形图、八功能叠加雷达图、差异摘要；跨模式 / 跨题库版本 / 跨人物时给出可比性提示 |
| 头像图片 | 可上传本地图片作为头像（自动裁成 160×160，存入数据库，随备份一起走，不另存文件） |
| 删除单次记录 | 二次确认；桌面端删除前自动备份 |

不包含：心理状态评估（Phase 4）、正式报告模板（Phase 4）、AI（Phase 5）。

| 位置 | 内容 |

| `apps/mindscope/src/components/SplashScreen.vue` | 启动动画 |

## 4. 验收标准

- 人物卡详情页显示的次数、最近时间、最近类型与数据库一致；没有测评记录时显示明确的空状态，不显示示例数据
- 趋势图只在有 ≥ 2 次结果时显示，否则提示"至少需要两次测评"
- 对比页：同模式同版本直接对比；跨模式、跨题库版本、跨人物时显示相应提示
- 删除单次记录后，详情页、历史页、首页统计同步更新；其他人物的数据不受影响
- 上传头像后重启仍在；超大图片会被压缩；非图片文件被拒绝
- 历史筛选结果正确（单元测试 + E2E）
- 网页端与桌面端均可用，打印/导出 PDF 版式正常
