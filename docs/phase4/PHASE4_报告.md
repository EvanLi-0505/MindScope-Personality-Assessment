## 1. 交付内容

| 功能 | 说明 | 关键文件 |
|---|---|---|
| 四个自评量表 | **PHQ-9**（抑郁症状）、**GAD-7**（焦虑症状）、**WHO-5**（主观幸福感，原始分 × 4）、**MindScope 压力自评**（自编，界面和报告都标明"非标准化"）。分级全部来自官方资料，来源、许可、引用写在每个量表文件里 | `packages/banks/wellbeing/*.json` |
| 量表引擎 | 通用 `sum@1` 计分：反向题、乘数、分级、"安全题"独立判断（不受总分影响）；校验器保证分级覆盖每一个可能的分数且不重叠 | `packages/core/src/scale/` |
| 自评作答页 | 所有题目一页作答，每答一题立即保存；未答完不能提交（会滚动到第一道空题）；中途离开后可从首页 / 测评页继续 | `CheckPage.vue` |
| 求助卡片 | PHQ-9 第 9 题（自伤念头）≥ 1 时，**无论总分多少**，作答页、结果页、报告里都显示求助资源：全国心理援助热线 12356、紧急情况 110 / 120、联系信任的人、境外拨当地热线。只显示文字，不联网。报告里不能关掉这一块 | `SafetyCard.vue`、`banks/src/index.ts` |
| 自评结果页 | 分数、分级、分数条、解读、自我照顾建议、"建议和专业人士聊一聊"（达到官方建议转介的分数时）、同一量表历次趋势、使用须知、作答明细、量表来源与许可 | `CheckResultPage.vue` |
| 人物卡"心理状态记录" | 每个量表显示最近一次分数和分级，两次以上显示趋势图；"开始心理状态自评"按钮。与人格结果分开显示，人格的"测评次数""最近类型"不受影响 | `WellbeingSummary.vue` |
| 历史页 | 新增"心理状态记录"列表（跟随人物 / 日期筛选，可查看、可删除）；人格图表和人格列表不混入自评 | `WellbeingTable.vue`、`HistoryPage.vue` |
| 正式 PDF 报告 | 人格和自评各一套 A4 模板：Logo 抬头、报告编号、姓名 / 时间 / 测评工具、编号章节、**每页页脚的"第 x 页 / 共 y 页"和免责短句**、结尾声明。导出前可预览、可勾选包含的部分（人格：四维 / 八功能 / 性格描述 / 方法；自评：建议 / 趋势；两者都有可选的"作答明细"附录）。量表来源与许可、求助信息始终打印 | `ReportPage.vue` |
| 导出后打开 | 桌面端导出后出现"打开文件""在文件夹中显示"。Rust 端只允许打开**本次运行中由 MindScope 自己导出的 PDF**，其他路径一律拒绝 | `commands.rs::open_exported` |
| 数据库 | 迁移 0003（量表元数据列）；升级前自动备份 | `0003_instrument_meta.ts` |

## 3. 本阶段发现并修复的问题

| 问题 | 怎么发现的 | 修复 |
|---|---|---|
| GAD-7 的"有意义变化"阈值找不到官方出处 | 核对资料 | 删除，只保留有出处的 PHQ-9（5 分）和 WHO-5（10 分） |

## 4. 许可与合规

- PHQ-9、GAD-7：公有领域，官方手册明确无需许可。中文措辞采用国内研究广泛使用的版本；**官网的官方简体中文译本没有找到可下载的文件，所以没有逐字核对**，这一点在应用内和 NOTICE 都写明了。
- WHO-5：© WHO 2024，CC BY-NC-SA 3.0 IGO（**仅限非商业**）。中文用 WHO 网站发布的中国大陆版；WHO 要求的译本免责声明会显示在每次 WHO-5 结果和报告里。NOTICE 写明：若有人拿 MindScope 做商业用途，必须移除 WHO-5 文件。
- DASS-21、PSS-10 经评估后**没有采用**（许可不明确允许在公开应用里显示分数）。
- 所有页面和报告都写明"自我筛查，不是诊断"；不会从人格类型推断心理状态。
