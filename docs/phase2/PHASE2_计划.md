# Phase 2 — 16 型人格核心：计划

> 日期：2026-10-22　状态：已完成，见 [PHASE2_报告.md](PHASE2_报告.md)

## 1. 目标

用户可以为某张人物卡完成一次完整的 16 型人格测评（四种模式任选），中途关闭也能继续；交卷后得到由真实作答计算的结果，包括四维倾向、八功能八边形雷达图和性格描述，并保存到该人物卡。

## 4. 步骤

1. 核心类型与题库校验器 → 单元测试
2. 评分引擎 → 单元测试（反向计分、缺失、边界、16 型功能栈）
3. 自适应选题器 → 单元测试 + **模拟答题**（用已知倾向的虚拟答题者验证引擎能否还原类型）
4. 编写题库与 16 型描述 → 用校验器检查
5. 存储层仓库 → 单元测试（会话、答案修改、交卷事务、隔离、题库不可变）
6. 界面 → 浏览器实测
7. E2E（完整做完一次快速测试、中途刷新继续）+ 桌面 exe 冒烟
8. 报告

## 5. 验收标准

- 评分引擎单元测试全部通过，包括反向计分、缺失答案、接近均衡、数据不足
- 固定种子 + 相同答案 → 完全相同的出题顺序和结果
- 模拟答题中，普通模式对倾向明确（|S| ≥ 0.3）的维度判断准确率 ≥ 95%
- 中途关闭/刷新后回到原来那道题，已答内容不丢
- 交卷后结果写入数据库，并出现在人物卡上；重启后仍可打开结果页
- 八功能某项题数不足时，雷达图不显示该项数值并标注"数据不足"
- 结果页明确标注"自编题库、未经常模验证"，快速模式标注"初步参考"
- 网页端与桌面端都能完成一次测评
