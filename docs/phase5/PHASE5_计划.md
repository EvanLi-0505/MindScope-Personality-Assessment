# Phase 5 — AI 扩展（可选）：计划

> 日期：2026-10-24　状态：已完成（见 [验收报告](PHASE5_报告.md)）

## 1. 目标

1. **AI 设置页**：服务商、Base URL、模型、温度、最大长度、超时，API Key 安全保存，连接测试，使用状态。
2. **三项 AI 功能**（都在人物卡详情页，全部由用户点击触发）：
   - 人格历史分析：总结多次人格测评的稳定部分和变化（可选加入心理状态自评）
   - 成长记录总结：基于用户自己写的成长记录生成反思建议
   - 个性化建议：学习、工作、沟通方面的建议
3. **成长记录**（本地功能，不需要 AI）：人物卡里按日期记录观察和感受。
4. **数据发送确认、隐私控制、错误处理、网络记录**。
5. 你在 Phase 4 验收时提出的：**首页概览卡片可点击跳转**。

AI 默认关闭。没有配置 AI 时，所有基础功能照常可用。

## 3. 关键设计

### 3.1 API Key 安全

- 桌面版用 **Windows DPAPI** 加密后保存在 `config/ai-key.dat`（仍在软件文件夹内，不写 C 盘）。只有同一台电脑上的同一 Windows 账户能解密；换电脑或换账户后需要重新填写。
- 也可以选择**"只在本次运行中使用，不保存"**。
- Key 只存在 Rust 端：界面只能看到"已保存（尾号 ••••abcd）"，不能读回明文。日志、数据库、备份、导出报告、错误提示里都不会出现 Key（错误信息会把 Key 替换掉，有单元测试）。
- 网页版：浏览器安全策略禁止访问外部网络，也无法安全保存密钥，所以**网页版不提供 AI**，界面会说明原因。

### 3.2 联网与同意

- 第一次开启 AI 时弹出说明：数据会发到哪里、只在你点击时发送、每次发送前都会给你看内容、记录在哪里。
- **每次发送前都要确认**：显示服务商地址、模型、数据类别（可勾选），以及"查看将发送的完整内容"（逐字展示）。
- Rust 端二次把关：AI 未开启、地址不合规或没有 Key 时直接拒绝，不发请求。
- 每次请求（含连接测试）记录到「数据与存储 → 网络」：时间、地址、用途、数据类别、字节数、用量、结果。**不记录内容和 Key**。

### 3.3 数据最小化

| 数据 | 默认 | 说明 |
|---|---|---|
| 姓名、备注、头像 | **从不发送** | 用"这位用户"代替 |
| 人格结果（类型、四维、八功能分数、模式、日期） | 发送 | 分析必需 |
| 历次人格结果 | 发送 | 历史分析需要 |
| 年龄段 / 性别 / 职业 | 不发送 | 可勾选；年龄只发年龄段（如 25–29 岁） |
| 心理状态自评分数 | 不发送 | 可勾选，勾选时额外提示这是健康信息；只发量表名、分数、分级、日期，不发逐题答案 |
| 成长记录 | 仅"成长记录总结"发送 | 最近 20 条，可在预览中看到全部原文 |

### 3.4 AI 输出的约束

- 提示词模板放在 `packages/core/src/ai/`（版本 `ai-prompt@1`，可单测），规定：标明依据、不虚构历史、不把相关说成因果、不预测人格未来变化、不做诊断、数据不足时明确说明局限。
- 界面始终标注"AI 生成 · 仅供参考"，并在下方列出**本次依据**（由程序生成，不靠 AI 自述）。
- 如果发送的数据里有 PHQ-9 第 9 题 ≥ 1，**程序**会在 AI 内容旁固定显示求助卡片，不依赖 AI 的回答。
- AI 返回的文本按安全的 Markdown 子集显示（标题、列表、粗体），HTML、链接和图片一律不渲染。
- 生成结果保存在本地数据库，可以查看和删除，也可以打印。

### 3.5 架构（类似 LangChain4j 的分层）

```
core/ai     提示词模板 + 数据去标识化 + 依据生成（纯函数，MIT）
platform    AiProvider 接口：desktop = Rust 客户端；测试构建 = 本地模拟（不联网）
src-tauri   ai.rs：密钥（DPAPI）、HTTP 客户端（reqwest + Windows 系统 TLS）、SSE 解析、取消、网络记录
```

## 5. 测试

- 单元：提示词与去标识化（确认姓名、备注不会出现在发送内容里）、依据生成、Markdown 安全渲染（XSS 用例）、存储层
- Rust：用本地模拟服务器测试流式解析、401 / 429 / 超时 / 取消、Key 不出现在错误里、地址校验、DPAPI 加解密
- E2E：测试构建里的模拟 AI（不联网）走完整流程：开启 → 同意 → 预览 → 生成 → 保存 → 删除；错误提示；网页版正式构建不显示 AI
- 桌面冒烟：本机启动模拟服务器，exe 走真实的 Rust 客户端和 DPAPI 完成一次分析并导出 PDF
- **真实百炼接口需要你的 Key**，验收时请你在桌面版填 Key 做一次连接测试和一次分析

## 6. 验收标准

- 未开启 AI、未填 Key、断网时，基础功能完全正常，且没有任何网络请求
- 每次发送前都有确认和完整预览；姓名和备注从不发送
- Key 不出现在日志、数据库、备份、导出报告和界面中
- 401 / 429 / 超时 / 断网都有清楚的中文提示，可以重试或取消
- AI 内容有"AI 生成"标注和依据；PHQ-9 第 9 题触发时固定显示求助卡片
- 「网络」页能看到每次请求的记录
- 首页概览卡片可以点击跳转
