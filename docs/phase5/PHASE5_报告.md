# Phase 5 — AI 扩展（可选）：验收报告

> 日期：2026-10-24　状态：**已完成，等待你验收**　版本：0.5.0

## 1. 交付内容

| 功能 | 说明 | 关键文件 |
|---|---|---|
| AI 设置页 | 侧边栏 / "我的"新增「AI 助手」。开关（首次开启有说明，需要明确同意）；服务商预设：百炼北京、百炼新加坡、自定义 OpenAI 兼容接口；Base URL（只允许 https，http 只限本机）；模型名称；温度、最大长度、超时；连接测试（先确认，测试消息不含个人数据）；使用状态（次数、成功数、tokens、最近一次结果） | `AiSettingsPage.vue`、`ai/config.ts` |
| API Key 安全 | Windows DPAPI 加密后存在 `config/ai-key.dat`，或选择"只在本次运行中使用"。Key 只在 Rust 端，界面只显示"••••尾号"。换电脑或换账户后无法解密，会提示重新填写 | `src-tauri/src/ai.rs` |
| 三项 AI 分析 | 人物卡新增「AI 分析」：**人格历史分析**、**成长记录总结**、**个性化建议**。逐字流式显示，可停止；完成后保存在本地，可删除，也可打印 / 导出 PDF | `components/ai/AiSection.vue`、`ReportPage.vue`（kind = ai） |
| 发送前确认 | 每次都弹出确认框：发送到哪个地址和模型、包含哪些数据（可勾选），以及"查看将发送的完整内容"（逐字显示）。心理状态分数默认不发送，勾选时额外提醒这是健康信息 | `AiSection.vue` |
| 数据最小化 | 姓名、备注、头像、逐题答案**从结构上就无法发送**（提示词输入类型里没有这些字段）；年龄只发 5 岁一档的年龄段；成长记录最多 20 条、每条 500 字 | `packages/core/src/ai/prompt.ts` |
| AI 内容约束 | 提示词模板 `ai-prompt@1`：只根据数据说话、不编造、不把相关说成因果、不预测人格变化、不诊断、数据不足要说明。界面固定标注"AI 生成 · 仅供参考"，**依据由程序统计**（不靠 AI 自述）；发送的数据里有 PHQ-9 第 9 题 ≥ 1 时，程序固定显示求助卡片 | `prompt.ts`、`AiNoteView.vue` |
| 安全显示 | AI 返回的文本只渲染标题、列表、粗体；HTML、链接、图片一律当作普通文字显示 | `ai/markdown.ts` |
| 成长记录 | 人物卡新增「成长记录」：按日期记录变化和感受，可编辑、删除。只存在本机 | `GrowthNotes.vue`、`repositories/notes.ts` |
| 网络记录 | 「数据与存储 → 网络」显示每次请求：时间、地址、模型、用途、数据类别、大小、tokens、结果；可清空。**不记录内容和 Key** | `NetworkLog.vue` |
| 首页卡片跳转 | 你在 Phase 4 验收时提出的：人物卡 → 人物列表；已完成测评 → 历史；未完成测评 → 测评页的继续列表；最近一次测评 → 那次的结果页（人格或自评）。没有数据的卡片不可点击；支持键盘 | `HomePage.vue`、`stats.ts` |
| 数据库 | 迁移 0004：`growth_notes`、`ai_notes`，`network_audit` 增加 `model`、`tokens`；升级前自动备份 | `0004_ai_growth.ts` |
| 网页版 | 不提供 AI（浏览器安全策略禁止外部请求，也没有安全保存 Key 的地方），界面说明原因 | `platform/web` |

**架构**（类似 LangChain4j 的分层）：`core/ai`（提示词、去标识化、依据，纯函数）→ `AiBridge` 接口（桌面 = Rust 客户端；测试构建 = 本机模拟）→ `src-tauri/ai.rs`（Key、HTTP、SSE、取消、网络记录）。Rust 端会再次检查：AI 未开启、地址不合规或没有 Key 时直接拒绝；服务商地址和模型从已保存的设置读取，不接受界面临时传入。

## 4. 没有验证的部分（需要你来）

**真实的百炼接口我没有调用过**，因为需要你的 API Key（我不会、也不应该使用任何真实 Key）。所有联网逻辑都已用本机模拟服务器在真实 exe 上跑通，但请你验收时：

1. 打开桌面版 →「AI 助手」→ 开启 → 选"阿里云百炼（北京）"→ 粘贴你的 Key → 保存 → **连接测试**
2. 如果提示模型不存在，在百炼控制台查看可用的模型名（官方文档当前示例用的是 `qwen3.8-max`；预设默认是 `qwen-plus`），填进去再测
3. 到一张有测评记录的人物卡 → AI 分析 → 人格历史分析 → 看一下预览 → 确认发送

如果你用的是业务空间专属地址（`https://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`），直接粘贴到 Base URL 即可。
