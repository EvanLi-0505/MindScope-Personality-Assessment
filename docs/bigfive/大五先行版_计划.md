# 大五人格先行版（0.7.0）：计划

> 日期：2026-10-25　状态：进行中　方案：A（IPIP 公有领域题目 + MindScope 自行翻译）

## 1. 目标

在 16 型人格之外，增加一个**大五人格（Big Five）先行版**测评：开放性、尽责性、外向性、宜人性、情绪敏感性（神经质）。先行版的含义：题目是经过研究验证的英文原题，但中文是我们自己翻译、还没有经过验证，也没有中国人群常模，界面和报告都会明确标注。

## 2. 题目来源（已核实，2026-10-25）

IPIP 官网说明："The items and scales are in the public domain"，可以不经许可、免费使用，因此可以翻译、改编，与本项目的开源许可兼容。

| 模式 | 来源 | 题数 | 结果 |
|---|---|---|---|
| 快速 | Mini-IPIP（Donnellan 等，2006） | 20 | 五个维度 |
| 普通 | IPIP 大五标记 50 题（Goldberg，1992） | 50 | 五个维度 |
| 资深 | IPIP-NEO-120（Johnson，2014） | 120 | 五个维度 + 30 个子维度 |

- 题目原文、所属维度和计分方向（正向 / 反向）全部按 IPIP 官网的计分键录入。
- 同一句题目在不同量表里可能属于不同维度（例如 "Feel others' emotions" 在 50 题版属于宜人性，在 120 题版属于开放性的"情绪感受"子维度），所以**维度和方向按模式分别记录**。
- **文化改编**：120 题版"价值观开放（O6）"中有两题是"倾向于投票给自由派 / 保守派候选人"，不适合中文语境。改为两道价值观开放程度的中性题目，标注为"MindScope 改编"，并在结果中说明该子维度与原版不完全相同。

## 3. 计分（`likert-mean@1`）

- 5 级作答：非常不符合 / 比较不符合 / 不确定 / 比较符合 / 非常符合（1–5）。反向题按 6 − 原分计算。
- 维度分 = 该维度题目的平均分（1–5），同时换算为 0–100（(平均分 − 1) ÷ 4 × 100），并给出标准误。
- **不显示百分位**：没有常模，不说"超过了多少人"。粗分档按量表区间三等分（1–2.33 偏低 / 2.33–3.67 中等 / 3.67–5 偏高），并注明"这是在量表上的位置，不是与人群比较"。
- 情绪敏感性（神经质）分数越高，越容易体验到焦虑、烦躁等负面情绪；文案避免贬义。

## 4. 界面

| 位置 | 内容 |
|---|---|
| 开始测评 | 新增"大五人格（先行版）"，选择快速 / 普通 / 资深 |
| 答题页 | **复用 16 型的答题页**：进度矩阵、标记、键盘 1–5、核对页、暂停续答；不显示正在测哪个维度，避免影响作答 |
| 结果页 | 五边形雷达图、五个维度的分数与解释（高 / 中 / 低三档文案）、资深模式的 30 个子维度、计算方法、局限、题目来源与许可 |
| 人物卡 | "大五人格"区块：最近一次结果、两次以上显示趋势 |
| 历史页 | 大五人格记录列表（查看、删除） |
| 报告 | 正式 PDF 报告（与 16 型、自评报告同一套版式） |

与 16 型分开记录、并列显示，**不互相换算**。AI 功能暂不使用大五数据（AI 已搁置）。

## 5. 存储

不改表结构：大五作为 `personality` 类测评工具（`ipip-b5`），以计分引擎区分；16 型的查询限定为 16 型引擎，避免混入。题库版本同样不可变、带内容哈希。

## 7. 验收标准

- 三个模式的题数和每个维度 / 子维度的题数与原量表一致（快速 4×5、普通 10×5、资深 24×5 且每个子维度 4 题）；每道题的维度和方向与官方计分键一致（单元测试逐条核对）
- 反向计分、未答题、全部同一答案等情况计分正确
- 大五结果不出现在 16 型的历史、对比和人物卡类型里；16 型的功能不受影响
- 完整作答、续答、结果、人物卡、历史、报告都可用（E2E + 桌面冒烟）
- 所有页面标注"先行版"、自译未验证、无常模
