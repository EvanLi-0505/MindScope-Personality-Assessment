# 大五人格先行版（0.7.0）：验收报告

> 日期：2026-10-25　状态：**已完成，等待你验收**　方案：A（IPIP 公有领域题目 + MindScope 自行翻译）

## 1. 交付内容

| 内容 | 说明 |
|---|---|
| 题库 `ipip-b5@0.1.0` | 156 道不重复的题目（50 题版与 120 题版共享 14 道），英文原文按 IPIP 官网逐字录入，每道都有中文译文；三个模式的维度、子维度和计分方向分别记录 |
| 三个模式 | 快速 = Mini-IPIP 20 题；普通 = IPIP 大五标记 50 题；资深 = IPIP-NEO-120（120 题，30 个子维度，每个 4 题） |
| 文化改编 | "价值观开放（O6）"中两道"倾向于投票给自由派 / 保守派候选人"的题目，换成"我愿意重新审视自己长期持有的观念"（正向）和"我认为传统的做法总是最好的"（反向），在题库中标注被替换的原题，结果页和报告中说明 |
| 计分 `likert-mean@1` | 反向题 6 − x；维度 / 子维度 = 平均分，换算 0–100，附标准误；作答不足 75% 不计分；偏低 / 中等 / 偏高按量表三等分，**明确说明不是常模** |
| 答题 | 复用 16 型的答题页：进度矩阵、标记、键盘 1–5、核对页、暂停续答；不显示正在测哪个维度 |
| 结果页 | 五边形雷达图、五个维度的分数与含义、"与 TA 相处"（只列明显偏高 / 偏低的维度）、资深模式 30 个子维度、计算方法（含每个维度的平均分、标准误和题数）、使用须知、来源 / 许可 / 引用 / 译本声明 |
| 其他页面 | 人物卡"大五人格"区块（最近一次 + 两次以上显示趋势）、历史页列表（按人物 / 模式 / 日期筛选，可删除）、首页"最近一次测评"可跳转、正式 PDF 报告 |
| 与 16 型分开 | 16 型的历史、统计、对比、人物卡"测评次数 / 最近类型"都不含大五结果；不互相换算 |
| 文档 | NOTICE（IPIP 公有领域、译文 CC BY-SA 4.0）、README、用户使用说明第 5 节、开发者文档、CHANGELOG |

文案（维度解释、相处提示）为 MindScope 自写，语气中性；"神经质"在界面上称为"情绪敏感性"，并说明这是心理学术语，不是贬义，也不是疾病。

## 2. 测试结果（全部实测）

| 测试 | 结果 |
|---|---|
| 题库结构 | 三个模式的题数（4×5 / 10×5 / 24×5）、30 个子维度各 4 题、无未使用或重复的题目 ✅ |
| 与官方计分键一致 | 每道 Mini-IPIP 题的维度和方向都与 50 题版一致；50 题版与 120 题版共享的题目中，只有已知的 "Feel others' emotions"（宜人性 / 开放性）一处不同；另有 11 道题对照官方计分键抽查 ✅ |
| 计分引擎 | 反向计分、全部同一答案、分档边界、作答不足、非法数值、子维度计分 ✅ |
| 存储 | 安装一次、内容改动被拒绝、结果与 35 个维度 / 子维度分数保存、与 16 型结果互不混入、未完成会话和首页能识别大五 ✅ |
| E2E（5 个） | 快速模式完整作答并核对分数与分档；与 16 型分开（人物卡、历史、首页）、删除；中途离开后续答；资深模式 120 题、30 个子维度和改编说明；快速连按不会跳过未答题 ✅ |
| 桌面版 | exe 冒烟中完成一次普通模式并导出大五 PDF（O = 100、N = 0，与预设作答一致）；发布测试 12 / 12 通过（包括从 0.6.0 数据升级） |

全部测试：单元测试 题库 39、核心 88、存储 49、应用 1380（文案与 Markdown 安全）；Rust 27；E2E 32；生产网页构建 E2E 1；桌面发布测试 12。

## 3. 本阶段发现并修复的问题

| 问题 | 怎么发现的 | 修复 |
|---|---|---|
| 固定题目列表的测评中，自动跳到下一题的瞬间按键会被忽略 | 大五 E2E（偶发） | 先保存位置再显示下一题，避免显示与按键锁错位 |
| 上面的修复让快速连按两次"下一题"只前进一题 | 16 型原有的 E2E | 连按时从"正在前往的题"继续计算；同时检查那一题是否已作答，不会跳过未答题（新增回归测试） |
| "中等"标签看不见 | 截图检查 | 标签的样式名和分数条中线的样式名冲突，已改名；测试加了"标签必须有实际宽度"的检查 |
